# Release Notes

## 1.0.0 demo release

InboxPilot now includes a runnable React/Vite UI, Express orchestration API, deterministic policy engine, mock Gmail adapter, FastAPI ML contract, safe draft flow, correction capture, activity feed, settings thresholds, CI configuration, Render blueprint, Dockerfiles, testing, and a complete learning guide PDF.

The current release is intentionally a credential-free demo. It does not claim live Gmail OAuth, MongoDB persistence, automated unsubscribe requests, or autonomous message sending. `npm install` currently reports dependency advisories in the transitive tree; review and pin updates before production deployment, then rerun the audit in CI.
